### 📊 SAP BO → Power BI Migration Accelerator

**AI-assisted automation platform for migrating SAP BusinessObjects reports to Power BI.**

* Designed a **3-tier modular architecture** separating metadata extraction, transformation and report generation
* Built an ETL pipeline converting semi-structured JSON into typed schemas
* Developed coordinate-based layout alignment for report components
* Used **Azure OpenAI** to translate SAP BO report parameters into Power BI expressions
* Achieved approximately **70–80% automation** across supported report complexity levels
* Reduced manual report re-authoring effort by approximately **80%**

`Python` `Azure OpenAI` `Power BI` `ETL` `JSON` `RDL`

* Reduced redundant LLM calls by approximately **80%**

`Next.js` `TypeScript` `Gemini` `Groq` `Inngest` `PostgreSQL` `RAG`
